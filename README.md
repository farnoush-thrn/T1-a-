# Appliance Energy Visualisation Website (COS30045)

## Overview
This is a demonstration website built for the **COS30045 Data Visualisation** unit. The website explores the energy consumption of televisions currently available in the Australian market.

## Features
- **Multi-page Structure:** Includes Home, Televisions, and About Us pages.
- **JavaScript Navigation:** The top navigation menu uses JavaScript event listeners (`window.location.href`) to swap between pages seamlessly, as per the assignment requirements.
- **Interactive UI:** Includes mouse-over feedback (hover effects) and highlights the currently active page.
- **Custom Styling:** Styled using pure CSS to match the project's logo color scheme (Brown, Yellow, Orange).
- **Data Placeholders:** Features a dedicated section to display KNIME charts answering 7 core business questions.
